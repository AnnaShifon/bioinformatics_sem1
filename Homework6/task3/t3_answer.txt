
3.1 BLASTp по базе SwissProt с матрицей BLOSUM62.
Гомолог миоглобина из Danio rerio (Accession Q6VHL8):
- E-value = 1e-32
- Bit Score = 115
- Per. Ident = 43.15%
- Query Cover = 95%

3.2 Поиск повторён с матрицей PAM30, остальные параметры без изменений.

3.3 Результаты для того же белка Danio rerio (Q6VHL8) с PAM30:
- E-value = 2e-27
- Bit Score = 119
- Per. Ident = 41.61%
- Query Cover = 97%

Сравнение:
Параметр        | BLOSUM62  | PAM30
E-value         | 1e-32     | 2e-27
Bit Score       | 115       | 119
Per. Ident      | 43.15%    | 41.61%
Query Cover     | 95%       | 97%

Главное изменение — E-value стал хуже на 5 порядков (1e-32 → 2e-27),
то есть находка стала менее статистически значимой. Per. Ident тоже
немного снизился. 

3.4 Объяснение наблюдаемых изменений.

PAM30 — это матрица, рассчитанная на очень близкие последовательности.
Она ожидает, что белки почти одинаковые, поэтому при совпадениях к подсчету добавляется большой match  и жёстко штрафуются любые замены, даже если аминокислоты похожи по свойствам. Для поиска близких гомологов это хорошо — матрица чувствительна к мелким различиям между очень похожими белками.

BLOSUM62 — матрица, построенная по белкам с ~62% идентичностью. Она
спокойнее относится к заменам похожих аминокислот (например, лейцин
на изолейцин), потому что такие замены часто происходят при
эволюционном расхождении. Поэтому она лучше подходит для поиска
более далёких гомологов.

Миоглобин человека и зебрафиша — далёкие гомологи. Между ними накопилось
много аминокислотных замен. BLOSUM62 адекватно оценивает эти замены
и даёт более значимый результат (E-value = 1e-32). PAM30 слишком
сильно штрафует каждую замену, из-за чего E-value получается хуже
(2e-27).

Вывод: PAM30 лучше подходит для близких гомологов, BLOSUM62 — для
умеренно далёких.
